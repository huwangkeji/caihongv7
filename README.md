## 一、项目简介

caihongv7 是一套面向**虚拟商品 / 卡密 / 代充代练**等场景的自助下单系统。用户在前台选择商品并支付后，系统自动发货（卡密或对接上游供货商下单），站长可在后台完成商品、订单、用户、分站、支付与模板的全流程管理。

本项目基于「虎王云自助下单系统 V7」整理而成，并已完成以下工程化改造：

- **去授权**：移除授权码绑定与在线校验逻辑，系统启动不再依赖任何外部授权服务。
- **去上报**：移除全部数据上报行为，远程通信接口替换为空实现（`NullApiClient`），不发起任何外部 HTTP 请求。
- **资源本地化**：前端 JS / CSS / 字体等静态资源全部本地化，可离线独立运行，零 CDN 依赖。

> 适用场景：虚拟卡密商城、游戏代充、会员充值、代理分站分销等。

## 二、功能特性

### 交易与商品

- 商品 / 分类管理，支持多级分类、排序、上下架与批量操作
- 卡密（Faka）库存管理，支持批量导入、批量清空
- 加价模板：按分类或商品灵活设置零售价 / 成本价
- 优惠券、秒杀、砍价、拼团等营销模块
- 订单管理：查询、补单、改价、退款与状态流转

### 支付与对接

- 多支付接口支持（支付宝 / 微信 / QQ 钱包等，按后台配置切换）
- 供货商（社区）对接：可接入多个上游货源站并统一管理
- 价格自动同步与库存同步
- 自动补单（CRON 定时任务）

### 站点与用户

- 分站（代理站）体系：独立后台、独立定价、独立结算
- 供货商端：独立入口，管理自有商品与提现
- 用户中心：订单查询、余额、充值、提现
- 会员等级、积分、签到、邀请推广

### 系统与运维

- 多套前端模板（内置 18 套，支持 PC / 移动端分别设置）
- 后台功能权限校验（按模块授权，超管不受限）
- 防 CC 攻击、验证与 IP 策略、操作日志
- 短信（腾讯云短信）与邮件通知
- 伪静态（URL 重写）支持
- 数据迁移与备份工具

## 三、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Linux（CentOS 7+ / Ubuntu 18+）推荐，Windows 亦可 |
| Web 服务器 | Nginx 或 Apache |
| PHP | **7.4**（推荐 7.4.x NTS） |
| 数据库 | **MySQL 5.6+**（推荐 5.7） |
| 其他 | 无强制 Redis 依赖 |

### PHP 扩展依赖

| 扩展 | 说明 |
|---|---|
| `pdo` / `pdo_mysql` | 数据库访问（必需） |
| `mbstring` | 多字节字符串处理 |
| `openssl` | 加密与安全通信 |
| `curl` | 上游接口对接 |
| `gd` | 验证码与图片处理 |
| `fileinfo` | 上传文件类型识别 |
| `zip` | 压缩包处理 |

> 上述扩展通常已随 PHP 安装包提供；虚拟主机环境可能缺失，需手动开启。

## 四、安装与部署

### 1. 获取源码

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

或直接下载 Release 源码包并解压。

### 2. 上传与权限

将源码上传至站点根目录，并确保 PHP 进程对以下目录可读写：

```bash
# 需要写入权限的目录（示例）
chmod -R 755 ./
# 若使用 Nginx，确保运行用户（如 www-data / nginx）对项目目录有读写权限
```

同时确保已配置好域名解析，使其指向服务器。

### 3. 创建数据库并导入

```bash
mysql -u root -p
```

```sql
CREATE DATABASE `daishua` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
EXIT;
```

```bash
mysql -u root -p daishua < install/install.sql
```

> 若仓库中 `install/` 目录仅包含增量更新脚本（`update.sql` 等），请以目录内实际提供的完整数据库文件为准导入；升级场景可按需执行增量脚本。

### 4. 配置数据库连接

编辑根目录 `config.php`：

```php
<?php
$dbconfig = array(
    'host'   => 'localhost', // 数据库服务器
    'port'   => 3306,        // 数据库端口
    'user'   => 'root',      // 数据库用户名
    'pwd'    => '123456',    // 数据库密码
    'dbname' => 'daishua',   // 数据库名
    'dbqz'   => 'shua',      // 表前缀
);
```

> **安全提示**：请务必修改为自己的数据库账号与强密码，不要使用示例中的默认值。

### 5. 执行安装向导

浏览器访问：

```
http://<你的域名>/install/
```

按页面提示填写数据库信息、管理员账号等，完成安装。

### 6. 安装后收尾（重要）

安装完成后**必须**执行以下操作之一，防止安装向导被重复利用：

```bash
rm -rf install/
# 或
touch install/install.lock
```

### 7. 伪静态（可选）

若使用 Nginx，可参考根目录 `nginx.htaccess` 配置重写规则，或在站点配置中追加：

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

## 五、基本使用示例

### 5.1 访问入口

| 入口 | 地址 | 说明 |
|---|---|---|
| 前台商城 | `http://<域名>/` | 用户浏览与下单 |
| 后台管理 | `http://<域名>/admin/` | 站长管理全站 |
| 用户中心 | `http://<域名>/user/` | 注册用户登录 |
| 供货商端 | `http://<域名>/sup/` | 供货商管理商品与结算 |

### 5.2 后台快速上手

1. **站点配置**：`后台 → 系统设置 → 网站信息配置`，设置站点名称、客服 QQ、关键词等。
2. **添加分类**：`商品管理 → 商品分类`，建立商品分类。
3. **添加商品**：`商品管理 → 添加商品`，填写名称、价格、成本与库存（或卡密）。
4. **配置支付**：`系统设置 → 支付接口配置`，填写对应渠道参数并启用。
5. **对接货源**（可选）：`社区/供货商` 相关菜单，配置上游站点地址与账号。
6. **选择模板**：`系统设置 → 首页模板设置`，为 PC / 移动端分别选择模板。

### 5.3 前台下单流程

```
用户选择商品 → 填写下单信息 → 选择支付方式 → 完成支付
      → 系统自动发货（卡密直出 或 向上游供货商下单）
      → 用户可在「订单查询」查看卡密/进度
```

### 5.4 定时任务（自动补单）

如需启用自动补单，可添加系统计划任务：

```bash
# 每 5 分钟执行一次
*/5 * * * * /usr/bin/php /path/to/your/site/cron.php >> /var/log/nodeapi-cron.log 2>&1
```

后台 `系统设置 → 计划任务` 中可获取外网 CRON 监控地址与执行间隔配置。

## 六、项目目录结构

```
.
├── admin/                 # 后台管理端（113 个 PHP 入口 + 静态资源）
│   ├── head.php           #   后台公共头部（注意：受登录校验，字节数受约束）
│   ├── set.php            #   系统设置分发入口
│   ├── shopedit.php       #   商品编辑
│   └── *-table.php        #   列表数据源（AJAX 分页/搜索）
├── user/                  # 用户中心（订单、余额、充值、提现）
├── sup/                   # 供货商端（商品、结算、提现）
├── includes/              # 核心库与引导层
│   ├── bootstrap.php      #   启动引导（14 阶段）
│   ├── common.php         #   委派存根
│   ├── lib/               #   DB / Cache / Template / Price / Plugin 等
│   └── plugins/           #   第三方社区（货源站）对接插件
├── template/              # 前端模板（内置 18 套：default / Agod / Fall* / NewFaka 等）
├── assets/                # 静态资源（JS / CSS / 图片，已全部本地化）
├── config/                # 应用配置
├── install/               # 安装向导与数据库脚本
├── other/                 # 辅助工具与页面
├── src/                   # 扩展源码
├── api.php                # 对外 API 接口
├── ajax.php               # 前台 AJAX 接口
├── cron.php               # 计划任务入口
├── config.php             # 数据库配置（部署时需修改）
└── index.php              # 前台入口
```

> 数据库表默认前缀为 `shua_`（在 `config.php` 的 `dbqz` 中修改）。
